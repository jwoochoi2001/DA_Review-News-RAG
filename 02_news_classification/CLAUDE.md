# 공통 작업 규칙

- 프로젝트 루트를 기준으로 상대경로를 사용한다.
- 실제 파일명과 열 이름을 확인한 뒤 분석한다.
- data/raw의 원본은 수정하지 않는다. 가공 데이터는 data/processed에 둔다.
- 분석용 Python 코드는 analysis, 그래프는 outputs/figures, 표는 outputs/tables에 둔다.
- 코드는 재실행할 수 있게 작성하고 사용한 패키지와 버전을 기록한다.
- 제외하거나 대체한 데이터의 기준과 건수를 기록한다.
- 식별자, 정답 또는 예측 시점 이후 정보를 부적절하게 입력 변수로 사용하지 않는다.
- 요청한 단계까지만 수행한다. 요청하지 않은 Markdown 안내 문서나 임시 파일은 만들지 않는다.
