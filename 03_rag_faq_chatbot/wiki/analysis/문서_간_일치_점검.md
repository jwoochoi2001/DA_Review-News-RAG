# 문서 간 일치 점검 (매뉴얼 vs FAQ)

> 두 원본 문서의 같은 주제를 맞대어 본 결과. **서로 모순되는 내용은 발견되지 않았다.** FAQ는 매뉴얼의 요약본에 가깝다.

## 항목별 대조
| FAQ | 매뉴얼 | 결과 | 메모 |
|---|---|---|---|
| #1 누수 | §3.2 | 일치 | FAQ에는 결로 설명이 없다 |
| #2 냉방 약함 | §3.3 | 일치 | |
| #3 필터 청소 | §3.4 | 일치 | FAQ에는 '젖은 채 장착하면 곰팡이' 경고가 없다 |
| #4 희망 온도 | §3.1 | 일치 | |
| #5 필터 교체 시기 | §4.1 | 일치 | FAQ에는 정품 필터 구매처가 없다 |
| #6 필터 교체 방법 | §4.2 | 일치 | FAQ에는 '양손으로 잡고'가 없다 |
| #7 표시등 | §4.3 | 일치 | |
| #8 Wi-Fi 연결 | §1, §2 | 일치 | 5GHz 전용 네트워크 비연결은 매뉴얼에 명시, FAQ는 '2.4GHz만 지원'으로 표현 |
| #9 오프라인 | §7 | 일치 | |

| #14 정전 후 재연결 | §7 | 일치 | |
| #15 구성품 누락 | §1 | 일치 | |

## 발견한 점
- **매뉴얼에만 있는 세부 정보:** 곰팡이 주의(§3.4), 결로는 고장이 아님(§3.2), 정품 필터 구매처(§4.1), 스마트 플러그의 예약·소비 전력(§5), 구성품 목록(§1).
- **FAQ에만 있는 정보:** 없음. FAQ의 모든 답은 매뉴얼에 근거가 있다.
- **혼동 주의:** '7일'이 환불(미개봉 조건)과 구성품 교환 두 곳에 나온다. → [[환불과_교환]]
