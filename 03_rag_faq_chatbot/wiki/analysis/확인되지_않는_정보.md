# 확인되지 않는 정보 (문서에 없는 내용)

> 두 원본 문서에 **기재되어 있지 않은** 내용의 목록. 제품에 그런 정보가 없다는 뜻이 아니라 **이 문서들로는 확인할 수 없다**는 뜻이다. 상담 챗봇이 이 항목을 질문받으면 "확인할 수 없다"고 답해야 한다.

| 항목 | 문서에서 확인되는 범위 |
|---|---|
| 고객센터 전화번호 | '고객센터 전화(평일 09시~18시)'라고만 있고 번호가 없다 (출처: 제품_매뉴얼.md §6.3, 제품_FAQ.csv #13) |
| 교체 필터 가격·모델명 | 고객센터 또는 공식 온라인몰에서 구매한다는 것뿐이다 (출처: 제품_매뉴얼.md §4.1) |
| 스마트 플러그 예약의 설정 방법 | 예약 기능이 있다는 설명뿐이다 (출처: 제품_매뉴얼.md §5) |
| 보증 연장 방법 | 보증 기간(1년)과 무상·유상 구분만 있다 → [[보증_기간]] |
| 유상 수리 비용 | 유상 수리로 처리한다는 설명뿐이다 → [[보증_기간]] |
| 환불 시 배송비 부담 | 환불 조건만 있다 (출처: 제품_매뉴얼.md §6.2) |
| 이 문서가 다루지 않는 제품·기능 | 매뉴얼의 대상은 HB-AC300, HB-AP120, HB-PL10 세 제품이다 → [[개요]] |

새 소스를 넣어서 위 항목이 채워지면 이 페이지에서 지우고 해당 주제 페이지에 반영한다.
