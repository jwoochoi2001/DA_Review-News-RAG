# 한빛홈(HanbitHome) 앱

> 모든 한빛 스마트홈 제품이 연동되는 스마트폰 앱. 원격 제어, 예약 실행, 사용량 확인이 가능하다. (출처: 제품_매뉴얼.md §1)

## 설치와 제품 등록
앱스토어 또는 구글플레이에서 설치 → 회원가입 후 로그인 → 상단 '+' 버튼으로 제품 추가. 전체 순서는 [[초기_설치와_Wi-Fi_연결]]. (출처: 제품_매뉴얼.md §2)

## 앱에서 하는 일
| 기능 | 내용 | 페이지 |
|---|---|---|
| 필터 잔여 수명 확인 | 공기청정기 필터 잔여 수명을 백분율로 표시, 10퍼센트 이하이면 알림 (출처: 제품_매뉴얼.md §4.1) | [[HB-AP120_스마트_공기청정기]] |
| 필터 교체 완료 | 필터를 교체한 뒤 '필터 교체 완료' 버튼으로 잔여 수명을 초기화 (출처: 제품_매뉴얼.md §4.2) | [[필터_관리]] |
| A/S 신청 | '고객지원 > A/S 신청' 메뉴 (출처: 제품_매뉴얼.md §6.3) | [[AS_접수]] |
| 제품 상태 표시 | 연결이 끊기면 '오프라인'으로 표시 (출처: 제품_매뉴얼.md §7) | [[오프라인_오류와_재등록]] |
| 예약·소비 전력 | 스마트 플러그의 예약 제어와 실시간 소비 전력 (출처: 제품_매뉴얼.md §5) | [[HB-PL10_스마트_플러그]] |
