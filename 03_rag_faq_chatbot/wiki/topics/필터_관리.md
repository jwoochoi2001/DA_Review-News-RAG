# 필터 관리 (에어컨 청소, 공기청정기 교체)

> 에어컨 필터는 **씻어서 다시 쓰고**, 공기청정기 필터는 **교체**한다. 관리 방법이 서로 다르다.

| 구분 | 에어컨 [[HB-AC300_스마트_에어컨]] | 공기청정기 [[HB-AP120_스마트_공기청정기]] |
|---|---|---|
| 주기 | 2주에 한 번 청소 권장 (출처: 제품_매뉴얼.md §3.3, 제품_FAQ.csv #2) | 6개월에서 12개월마다 교체 (출처: 제품_매뉴얼.md §4.1, 제품_FAQ.csv #5) |
| 상태 확인 | 필터가 먼지로 막히면 냉방 효율이 크게 떨어짐 (출처: 제품_매뉴얼.md §3.3) | 앱에서 잔여 수명 확인, 10퍼센트 이하이면 알림 (출처: 제품_매뉴얼.md §4.1) |
| 세제 | 사용하지 않음 (출처: 제품_매뉴얼.md §3.4, 제품_FAQ.csv #3) | 해당 없음 |

## 에어컨 필터 청소 (출처: 제품_매뉴얼.md §3.4, 제품_FAQ.csv #3)
1. 전원을 끄고 플러그를 뽑는다.
2. 실내기 전면 커버를 위로 들어 올려 연다.
3. 필터를 살짝 당겨 분리한다.
4. 흐르는 물에 부드러운 솔로 먼지를 씻어낸다. **세제는 사용하지 않는다.**
5. 그늘에서 완전히 말린 뒤 다시 장착한다. **젖은 상태로 장착하면 곰팡이가 생길 수 있다.**

## 공기청정기 필터 교체 (출처: 제품_매뉴얼.md §4.2, 제품_FAQ.csv #6)
1. 본체 후면 커버를 양손으로 잡고 아래로 당겨 분리한다.
2. 기존 필터를 꺼낸다.
3. 새 필터의 비닐 포장을 완전히 제거하고 방향 표시(화살표가 본체 안쪽)를 맞춰 삽입한다.
4. 커버를 다시 닫는다.
5. 앱의 '필터 교체 완료' 버튼을 눌러 잔여 수명을 초기화한다. → [[한빛홈_앱]]

정품 교체 필터는 고객센터 또는 공식 온라인몰에서 구매한다. → [[고객센터]] (출처: 제품_매뉴얼.md §4.1)
