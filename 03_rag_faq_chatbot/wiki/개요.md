# 한빛 스마트홈 위키 개요

> 제품 매뉴얼과 FAQ를 소스로 LLM이 정리한 지식 위키. 소스는 `data/`에 있고 이 위키는 소스를 **고치지 않는다**. 소스는 **가상의 샘플 제품** 문서이다. (출처: 제품_매뉴얼.md 머리말)

- 앱과 지원 창구: [[한빛홈_앱]], [[고객센터]]
- 주제: [[초기_설치와_Wi-Fi_연결]], [[오프라인_오류와_재등록]], [[필터_관리]], [[에어컨_누수와_결로]], [[냉방이_약할_때]], [[표시등_색상]], [[보증_기간]], [[환불과_교환]], [[AS_접수]]

## 핵심 숫자 한눈에 보기
| 항목 | 값 | 출처 |
|---|---|---|
| 지원 Wi-Fi | 2.4GHz만 (5GHz 전용 네트워크는 연결 안 됨) | 제품_매뉴얼.md §1, 제품_FAQ.csv #8 |
| 페어링 모드 진입 | 리셋 버튼 5초, 거리 3미터 이내 | 제품_매뉴얼.md §2 |
| 에어컨 희망 온도 | 18도~30도 | 제품_매뉴얼.md §3.1 |
| 에어컨 필터 청소 | 2주에 한 번 권장 | 제품_매뉴얼.md §3.3 |
| 실외기 주변 비움 | 1미터 이내에 물건 없음 | 제품_매뉴얼.md §3.3 |
| 공기청정기 필터 교체 | 6개월~12개월, 잔여 수명 10퍼센트 이하 시 알림 | 제품_매뉴얼.md §4.1 |
| 스마트 플러그 정격 | 16암페어 | 제품_매뉴얼.md §5 |
| 품질보증 | 구매일로부터 1년 | 제품_매뉴얼.md §6.1 |
| 전액 환불 | 구매 후 7일 이내, 미개봉 | 제품_매뉴얼.md §6.2 |
| A/S 전화 | 평일 09시~18시 | 제품_매뉴얼.md §6.3 |
| 방문 수리 | 접수 후 영업일 기준 2~3일 이내 | 제품_매뉴얼.md §6.3 |
